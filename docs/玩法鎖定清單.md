# 玩法鎖定清單（M13.5 Feature Freeze）

> **2026-05-07 鎖定**：M13 + M13b 完成、機關清單鎖死。
> 後續 milestone（M14a / M15 / M15.5 / M16 / M16.5 / M14b / M17）**不再新增主角能力或機關種類**。
> 若有強烈想加 → 進入次要 backlog（[未來機關候選](謎題提案.md#七未來機制候選清單)）、不污染當前計畫。

---

## 一、主角動作集（鎖定）

| 動作 | 輸入 | 說明 |
|---|---|---|
| 走 | 左 / 右方向鍵 | 含加速度、不對稱地面/空中減速 |
| 跳 | Space / 上 | Coyote Time 0.15s + Jump Buffer 0.15s + Variable Jump Height |
| 錄製啟動 | LMB | 站亮光點上 = 重錄該槽位；其他 = 新錄製（FIFO 5 槽）|
| 結束錄製 | R | RecordingProxy 結束、本體解凍 |
| 召喚分身 | RMB / E | 召喚當前指向槽位的 Clone |
| 刪除槽位 | Q | 站亮光點上才有效 |
| 傳送 | R（在傳送門範圍）| 開啟地圖選目標、瞬移 |
| 開啟地圖 |  Tab   | 看世界地圖 + 槽位狀態 |
| 暫停 | ESC | PauseMenu（音量設定 / 繼續 / 主選單） |

**不再新增動作**。E 鍵互動類機關（如 Lever E 鍵版）已棄、改走跨壓觸發。

## 三、明確列為「不再新增」的事項

### 機關層
- ❌ 計時門（用 LogicGate + Tween 可組、不必獨立元件）
- ❌ NOT 按鈕（已被 LogicGate NOT mode 涵蓋）
- ❌ 移動平台（直線往返 / 圓周）— 用 TriggeredPlatform 替代
- ❌ 梯子（會改 Player 移動模式）
- ❌ 推箱子 / RigidBody2D 物件（與 deterministic 衝突）
- ❌ 蹬牆跳 / 黏壁（改核心移動手感）
- ❌ 重力翻轉（與錄製系統衝突）
- ❌ 鋸刃 / 雷射 / 擺錘 / 砲彈（基調衝突）
- ❌ 鑰匙鎖（基調衝突）
- ❌ 順序鎖 / XOR-gate（複雜度過高）

### 主角能力層
- ❌ 衝刺 / Dash（改核心移動）
- ❌ 攻擊鍵（基調衝突）
- ❌ E 鍵互動（已棄、改跨壓觸發）
- ❌ 雙跳 / 二段跳（與分身配合設計衝突）
- ❌ 蹲下 / 滑行

### 系統層
- ❌ 新輸入鍵（Recording.input_frames 結構鎖定為 left/right/jump）
- ❌ Time Rewind / 時光倒流（與「線性時間」設定衝突）
- ❌ 鏡像分身 / 反向錄製（過度抽象）
- ❌ 召喚預算系統（未來考慮、不在此階段）
- ❌ 多人連線（永遠不做）

## 四、進入 v2.0 backlog（freeze 後再考慮）

若 M16.5 外部測試後玩家強烈反饋需要、可進 backlog 但不影響 M13.5 後的 milestone：

| 候選 | 原因 |
|---|---|
| 殘骸進階謎題 | M13b 採方案 (c)、未來可考慮 (b) 永久消失語意 |
| 全域召喚預算 | 影響整體 balance、玩法複雜度增加 |
| 「告解房間」（殘骸博物館）| 純敘事彩蛋、非核心玩法 |
| 順序鎖 / XOR-gate | 後期深度謎題（11+ 房間後）|
| 動態尖刺 / 上升岩漿 | 加節奏壓力、可選增加緊張感 |

## 五、Freeze 與後續 milestone 的關係

```
M13b 完成 → 🔒 M13.5 玩法 Feature Freeze（本文件 commit）
              ↓
M14a 視覺接口框架（不改玩法、只建動畫/光照接口）
              ↓
M15 內容擴展（用既有機關設計 6-10 關）
              ↓
🔒 M15 結尾 關卡 Freeze
              ↓
M15.5 技術收斂（存讀檔技術可行性）
              ↓
M16 持久化 → 🔒 M16 結尾 存檔格式 Freeze
              ↓
M16.5 外部測試（看玩家回饋、進 v2.0 backlog 與否）
              ↓
M14b 裝飾視覺打磨
              ↓
M17 上架準備
```

任何階段若想破 freeze → 進 v2.0 / 不影響當前。
