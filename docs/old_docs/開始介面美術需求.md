# 開始介面美術需求 — 餘響 / Lingering Echo

> 目的：列出 [`TitleScreen.tscn`](godot/scenes/TitleScreen.tscn) 所需的所有視覺資源規格。
> 之後可自行製作、外發、或挑素材時對照需求。
>
> **目前狀態**：色塊原型（純暗藍底 + Godot 預設字型），需升級為符合「餘響」氛圍的版本。

---

## 一、設計方向

### 氛圍關鍵字
- **靜謐**（不喧嘩、不亮眼）
- **冷光中帶溫**（暗冷藍底 + 微暖金或微暖橙點綴）
- **時間感**（淡淡的「曾經」、不憂鬱也不熱情）
- **抽象**（不具象的人物、建築或場景；偏圖形 / 質感）

### 色彩系統

| 用途 | 色名 | Hex | 備註 |
|---|---|---|---|
| 主背景（最深） | 深空藍 | `#0D1019` | 比目前 `#0E0F1A` 更暗、更內斂 |
| 中層 | 暗夜藍 | `#1A2138` | 中間階、給漸層用 |
| 高光 | 微紫藍 | `#2C334D` | 用於漸層頂部、霧氣 |
| 主標 / 重要文字 | 月白 | `#F4F1E8` | 比純白柔、有溫度（米白偏黃）|
| 次要文字 | 灰藍 | `#8A93A8` | 副標、按鈕未啟用 |
| 點綴 / hover | 金黃 | `#E8B348` | 與遊戲內 Checkpoint 同色、強化「光點」記憶連結 |
| 點綴 / 分身 | 微藍 | `#6DB4FF` | 與 Clone 顏色呼應 |

設計原則：**80% 冷藍 + 15% 月白 + 5% 暖點綴**。暖色（金/藍）只在 hover、活躍狀態、重點裝飾才出現。

### 字型推薦

| 用途 | 中文字型 | 英文字型 | 風格 |
|---|---|---|---|
| 主標「餘響」 | 思源宋體 / 文鼎晶熱 / 王漢宗顏楷 | — | 偏宋 / 楷、中粗、有筆鋒 |
| 副標「Lingering Echo」 | — | EB Garamond / Cormorant Garamond | 細 serif、優雅 |
| 按鈕文字 | 思源黑體 Light/Regular | Inter Light / Lato Light | 細無襯線、現代 |
| 內文（設定面板） | 思源黑體 Regular | Inter Regular | 一般可讀 |

> Godot 4 用 `theme_override_fonts/font` 套 .ttf / .otf。建議放 `godot/fonts/` 資料夾。

### 對標作品（風格參考）

| 遊戲 | 抓什麼點 |
|---|---|
| **Cocoon** | 極簡標題、抽象生物剪影、深色帶光 |
| **Stray** | 字體細、不擠、暗色為主 |
| **Inside** | 標題單字、中央 layout、灰階為主 |
| **Outer Wilds** | 銀河 / 星雲背景、字型細而質感 |
| **Gris** | 漸層 + 飄動粒子、柔和氛圍 |
| **Death's Door** | 暗藍主調 + 暖光點綴、字型優雅 |

不參考的方向（避免）：
- ❌ Hollow Knight（過於漫畫感、線條粗）
- ❌ Hades（過於華麗、彩度高）
- ❌ Celeste（像素 retro、與本作走向不同）

## 二、Logo / 標題規格

### Layout 提案

```
                                        
                                        
              餘 響                     ← 主標（中文、大）
                                        
            Lingering Echo              ← 副標（英文、小、置中對齊）
                                        
                                        
              [ 開始遊戲 ]              ← 按鈕區
              [ 設 定 ]
              [ 離 開 ]
                                        
```

### 尺寸（基於 1280×720 viewport）

| 元素 | 字級 | 字距（letter-spacing）| 顏色 |
|---|---|---|---|
| 主標「餘響」 | 96-120 px | 0.15-0.2em（拉開氣勢） | `#F4F1E8` |
| 副標「Lingering Echo」 | 24-28 px | 0.05em | `#8A93A8` |
| 主副標間距 | 16-24 px | — | — |
| 兩字之間（餘 / 響）| 視字型可加 0.2-0.3em | — | — |

### 主標的兩種處理方向（擇一）

**方向 A — 純字型（最簡單）**
- 用 Godot Label + 自訂字型（思源宋體加粗）
- 優點：字數簡單、彈性高、易於修改
- 缺點：少了「設計感」

**方向 B — Logo 圖檔（推薦）**
- 把「餘響」設計成圖檔（含字型微調 / 描邊 / 微妙效果）
- 規格：
  - 格式：PNG（含 alpha）+ SVG（向量、未來 zoom 不破）
  - 尺寸：1024×400 px（高解析、Godot 自動縮）
  - 背景：透明
  - 內容：「餘響」+ 微妙的圖形元素（如下方一道淡光波 / 漣漪 / 細線）
- 優點：有獨特性、視覺記憶點

### Logo 視覺增強（可選 element）

- **底下一道漣漪線**：如聲波擴散的單道弧形、暗示「響」
- **「餘」字微微偏左淡化**：暗示「餘」=殘留、過去
- **「響」字邊緣有微光**：暗示「現在仍有回應」
- 整體不破壞文字辨識、只是 subtle 加分

## 三、背景視覺

### 取代目前純色 `#0E0F1A` 的方向

#### 推薦：**漸層 + 粒子飄動**

**漸層**：
- 從上到下：`#0D1019`（深空藍）→ `#1A2138`（暗夜藍）→ `#0D1019`（再回深）
- 或：頂部微微透出 `#2C334D` 的霧光、像月光透雲
- 用 ColorRect + 自訂 shader 或預製漸層 PNG (1280×720)

**粒子**：
- CPUParticles2D（已有粒子系統可重用）
- 數量：30-50 個（不要過多）
- 顏色：`#F4F1E8` 微透明（alpha 0.3-0.5）+ 偶爾混 `#6DB4FF` (10%)
- 大小：1-3 px
- 速度：很慢（10-30 px/s）、隨機方向、偏向上飄
- 生命：8-15 秒
- 視覺感：像「過去的塵埃飄浮」

#### 替代方案 A — 純漸層（無粒子）
- 優點：開發成本低、不分心
- 缺點：靜態、缺少氣氛

#### 替代方案 B — 靜態插畫
- 一張藝術 key art（如夜空 / 廢墟 / 兩個剪影並列）
- 規格：1280×720 PNG
- 缺點：與「餘響」風格搭配考驗大、需要美術功力

**最低可行**：純漸層 + 10-15 個慢速白點粒子。製作成本低、效果已遠超目前純色。

## 四、按鈕樣式

### 三個按鈕統一風格

**規格**：
- 尺寸：220 × 48 px（已有）
- 字級：22-24 px
- 字距：0.1em
- 字型：思源黑體 Light / Inter Light

**狀態**：

| 狀態 | 背景 | 文字色 | 邊框 |
|---|---|---|---|
| 普通 | 透明 | `#8A93A8`（次要灰）| 無 / 1px `#8A93A8` 細邊 |
| Hover | `#1A2138` 半透明（alpha 0.6）| `#F4F1E8`（月白） | 1px `#E8B348`（金邊）|
| Pressed | `#0D1019` | `#E8B348` | 1px `#E8B348` |
| Disabled | 透明 | `#4A5060` | 無 |

**轉場**：hover 0.15s tween（顏色平滑變化）。

### Godot 實作方式

用 `StyleBoxFlat`（程式建立 / theme 資源）：
- `bg_color` = 各狀態色
- `border_width_*` = 1
- `border_color` = `#8A93A8` / `#E8B348`
- `corner_radius_*` = 0（直角、避免圓角破壞 indie 質感）

或用 `Theme` 資源統一定義：建一個 `theme/title_buttons.tres`、按鈕 `theme = ...` 套用。

## 五、設定面板（SettingsPanel）

### 是否升級

**現況**：黑底白邊框、Music/SFX slider、返回按鈕。已能用、視覺一般。

**建議**：保留結構、調以下視覺：
- 背景從 `#000` → `#0D1019` 半透明 95%（與主背景一致）
- 邊框從純白 `#FFF` → `#8A93A8`（次要灰、不刺眼）
- Slider 軌道色：`#1A2138`、Slider 把手：`#F4F1E8`
- 「設定」標題用主標同字型（思源宋體）

### 不需要改的
- Layout（已合理）
- 互動邏輯（已成熟）
- 數值顯示（70% 等）

## 六、可選裝飾元素

### 加分但非必要的

#### 6.1 主標微妙呼吸動畫
- 標題 modulate.a 在 0.95-1.0 之間 4-6s 週期循環
- 像有微光呼吸、不是閃爍
- Godot Tween 一行解決

#### 6.2 標題進場動畫
- 進畫面時、主標從 alpha 0 → 1 漸入（1.5s）
- 副標延遲 0.5s 出現
- 按鈕再延遲 1s 從下淡入
- 給玩家「儀式感」開場、契合主題

#### 6.3 滑鼠 hover 按鈕時、漣漪粒子
- Hover 觸發小型粒子噴發（10-15 顆、淡金色、向外擴散 0.5s）
- 強化「按鈕被注意」的回饋
- 與遊戲內粒子系統一致

#### 6.4 BGM 同步律動（選做）
- 背景粒子速度隨 BGM 節奏微調
- 高難度、low-priority

## 八、Logo 設計細節（給美術 / 自製參考）

### 「餘響」字體微調建議

**思源宋體 SemiBold** 是基底、上面可加微調：
- 「餘」字略大 5-10%、「響」字略小、不對稱讓視覺有節奏感
- 「餘」字最後一筆（捺）尾端拉長、像聲波尾巴
- 「響」字「音」部位的點略淡（暗示「聲音消散中」）

避免：
- ❌ 加太多裝飾線（破壞極簡）
- ❌ 用書法毛筆字（過於東方主題、不貼近遊戲冷調氛圍）
- ❌ 描邊（讓字變廉價）

### 英文「Lingering Echo」設計

**EB Garamond Italic** 細斜體 是基底：
- 字距 0.05em
- 全大寫 vs 首字母大寫——首字母大寫更內斂（推薦）
- 「Lingering」與「Echo」之間用 em-dash 或大空格分開：`Lingering — Echo` 也是可能版本
