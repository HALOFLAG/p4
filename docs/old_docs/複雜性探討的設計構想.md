# 平行時空合作遊戲 — 設計構想

> 整合定稿。取代先前所有設計文件（v1+v2 設計構想、完整設計文件、其他的構思、當前問題、參考資料）。
> 版本：2026-05-01

---

## 一、一句話定義

一款 2D 平台跳躍解謎，玩家**透過錄製創造另一個版本的自己**，在同一張地圖上協作解謎。

**錄製鍵的瞬間，本體留在原地，玩家操控一個新的分身做出選擇**——錄完後光點留在地圖上標記這次分岔，玩家可以隨時把光點裝進 hotbar、按鍵召喚分身重演當時的選擇。

---

## 二、設計哲學

### 教學取向：Portal 路線（漸進式）
每個新機制都對應一個專屬的教學謎題，靠關卡設計引導玩家發現用法。
參考 Portal、Talos Principle、P.B. Winterbottom，**而非** Öoo / Leap Year 的「零教學」路線。

### 機制即主題（保留但放鬆）
盡量讓主題透過機制呈現，不靠對白文字。但**主題本身可以再校準**——玩家若把它當「錄製分身術」也 OK，不強迫他必須感受「平行時空」。

### 不亂加機制
原型已驗證的核心三件事（錄製、召喚、殘骸）足以撐起 60-100 個謎題。**寧可挖深既有機制（新型按鈕、新型機關、新環境互動），也不再加新核心系統。**

### 三條最重要的原則
1. **手感是門票**：跳躍與物理手感差，分身重播會雙倍痛苦
2. **可驗證才推進**：每個里程碑要能被玩通才算過
3. **頓悟比通關重要**：謎題設計圍繞「玩家會在某個瞬間想通什麼」

## 三、核心機制

### 錄製儀式

按下錄製鍵時的視覺與規則：

1. **本體留在原地**——變成半透明的「分裂點守候者」
2. **一個新分身出現在本體位置**——玩家從這一刻開始操控的就是這個分身
3. 畫面邊緣淡入細紅框（錄製模式視覺）
4. 玩家用分身做動作（走、跳）
5. 按結束鍵 → 分身消失、本體變回實體、**光點永久留在錄製起點**

**核心情感**：玩家在這個儀式中感受到「**我分裂出另一個我**」。視覺重量比一般動作大。

### 光點系統

- **數量無上限**，每錄製一次生一個
- 永久留在地圖上（不會消失）
- 視覺：地面上的淡色光圈、輕微脈動
- 互動：玩家走到光點上 → 觸發互動選單 → 可指派至 hotbar 槽位

### Hotbar 系統

- 玩家最多有 **5 個槽位**（按鍵 1-5）
- 每個槽位可裝載一個光點（一條分支）
- 按 1-5 → 從對應槽位的光點召喚分身重演當時的錄製動作
- 槽位可隨時換（走到別的光點裝載新的，舊的卸下）
- 卸下槽位的光點仍留在地圖上，只是不在快捷鍵裡

### 殘骸系統

**產生規則**：
- **只有「分身被機關殺死」會留殘骸**——關鍵設計，讓地圖上每個殘骸都是「**這條時間線走到死路**」的見證
- 玩家結束錄製、分身錄完自然消失：**不留殘骸**
- 玩家本體死亡：本關重置，所有殘骸清除

**時間視窗（5 個）**：
- **最近 5 個被殺死的分身**：殘骸有實體，可踩、可壓壓力板、可擋投射物
- 第 6 個分身被殺 → 最舊那個殘骸**變成痕跡**（純視覺，不可互動）
- 痕跡仍永久留在地圖上，傳達「世界記得這裡曾發生過」

### 碰撞規則

| 互動 | 行為 |
|---|---|
| 分身 vs 分身 | 互相穿透 |
| 玩家 vs 分身 | 完全碰撞 |
| 玩家 vs 殘骸（實體） | 完全碰撞，可踩、可壓 |
| 玩家 vs 痕跡 | 穿透 |
| 分身 vs 環境 | 完全碰撞，會被機關殺死 |

### 取消的概念

舊設計裡的「自爆」、「致命標記」、「主動犧牲是分支」全部簡化掉：
- **沒有「自爆」按鍵**——只有「結束錄製」鍵
- **沒有「致命標記」分層**——錄製階段死了就是模擬，主線召喚被殺才留殘骸
- **「主動犧牲」仍可行**——玩家想用分身擋投射物、踩尖刺，照樣可以，只是不需要事先標記

## 四、玩家流程

### 核心循環

```
1. 遊蕩      → 玩家在地圖中自由探索
2. 遇到障礙  → 看到一個過不去的地方
3. 觀察      → 分析結構（按鈕在哪、需要什麼）
4. 頓悟      → 「啊，如果有另一個我...」
5. 走到分裂點 → 在合適的位置按下錄製鍵
6. 做出選擇  → 操控分身做出那個關鍵的選擇
7. 結束錄製 → 光點留下、本體變實體
8. 裝載 hotbar → 走到光點、指派槽位
9. 召喚與配合 → 按 1-5 召喚，配合自己過關
10. 失敗、調整、再試
11. 通過    → 繼續探索，遇到下一個障礙
```

### 教學進程（Portal 路線）

每個新機制獨立教學謎題，謎題之間有緩衝區（無壓力開放空間）讓玩家自由實驗。

| Stage | 教學內容 | 範例謎題 |
|---|---|---|
| 1 | 基礎錄製 + 召喚 | 按鈕 + 門：玩家錄分身踩按鈕，本體跑過門 |
| 2 | 光點 + Hotbar | 兩個按鈕分別位於不同地點，需要分支 A 與 B 同時存在 |
| 3 | 殘骸（被動犧牲） | 壓力板無法到達，需讓分身踩尖刺後殘骸壓住 |
| 4 | 殘骸 5 視窗 | 刻意設計需要保留特定殘骸的關卡，玩家學會殘骸管理 |
| 5 | 多分身協作 | 需要 3 個分身按 3 個按鈕，本體跑過去 |

每個 Stage 結束後是緩衝區，讓玩家消化機制、自由實驗。**之後再無顯性教學**——玩家進入真正的開放探索。

## 五、美術與視聽方向

### 風格選擇
**Leap Year 式的極簡手繪 + 冷色調基底**

理由：
1. 多角色共存的視覺乾淨——多個半透明剪影同時在畫面上不會災難
2. 無臉無特徵的角色設計，讓玩家投射自己
3. 成本可控（適合獨立或小團隊）

### 顏色基調
- **基底**：藍灰、紫黑、深綠（冷色為主）
- **暖色強調**：玩家本體、出口、重要機關（橘、米白）
- **危險物件**：紅或亮橘（一眼可辨）
- 整體偏暗，但是「夜晚博物館」式的靜謐，不是恐怖風

### 角色視覺層次

| 對象 | 視覺處理 | 含義 |
|---|---|---|
| 玩家本體 | 純白、清晰實線、唯一的彩色 | 「現在最真實」 |
| 錄製中本體（守候） | 半透明白、輪廓淡化 | 「等待中的時間線」 |
| 分身 | 淡藍灰／淡紫，輪廓略細 | 「另一條時間線的我」 |
| 殘骸（實體） | 更淡、邊緣有微弱光暈、幾顆懸浮光點 | 「走到死路的可能性」 |
| 痕跡 | 極淡、快看不見 | 「正在被遺忘」 |
| 光點 | 地面淡光圈、輕微脈動 | 「這裡曾發生過分岔」 |

### 視聽核心原則
- **靜默比聲音有力**：關鍵時刻用短暫靜默作為情緒峰值
- **透明度即時間**：越「現在」越實心，越「過去」越淡
- **角色不交流，世界在交流**：分身不看玩家、不回應，情感由環境承接（光暈、回響、靜默）
- **沒有勝利音樂**：通關回響來自玩家自己感受

### 必須避免
寫實光影、複雜服飾、臉部表情、霓虹色、高飽和、像素風、過度精緻化、裝飾性物件

## 六、主題（待校準）

當前敘事框架：「**平行時空的自己合作**」。
但承認**主題是基於機制延伸出的，不是先有主題再做機制**。所以可以再校準。

可能的主題定位：
- A. 「**平行時空 / 時間分岔**」（高抽象、詩意，但難用視覺傳達）
- B. 「**過去與現在的協作**」（中抽象，較易理解）
- C. 「**靈魂出竅 / 分身術**」（低抽象，玩家直覺接受）
- D. **不強推主題**，純粹讓玩家自己詮釋

**目前不急著決定**——等中後期關卡設計開始時，自然會浮現哪個主題最契合實際玩起來的感覺。

## 七、待解決的設計問題

從討論還沒解決、影響後期的：

### UI 承載量
雖然 hotbar 解決大部分，但仍待設計：
- 光點互動選單長什麼樣？指派槽位的視覺流程？
- 玩家有 50 個光點時，地圖上密密麻麻的光點怎麼辨識？

### 開放地圖方向感
原型階段（單一房間）不是問題。中期開始做地圖時要面對：
- 主軸方向的視覺呈現
- 區域之間的清楚分隔
- 「進度感」的傳達

### 玩家死亡的重置範圍
- 玩家本體死亡 → 本關重置（清除殘骸、收回分身）
- 但「本關」邊界在哪？開放地圖沒有明確的「關」

待中期試玩決定。

### 主題層面
- **結局**：怎麼兌現玩家累積的情感？
- **環境敘事**：地圖角落要講什麼故事？

## 八、競品參考與差異化

### 主要參考路線：Portal / Talos Principle

| 元素 | 我們學什麼 |
|---|---|
| 教學節奏 | 每個新概念一個專屬謎題、無口頭教學 |
| 緩衝區設計 | 教學謎題之間的「無壓力消化區」 |
| 機制深度挖法 | 同一機制在不同場景變化用法（不加新機制） |

### 偷學的技巧

| 來源 | 偷學什麼 |
|---|---|
| Braid | 手感精準、機制與情感連結 |
| P.B. Winterbottom | 分身物理化、避免試錯地獄 |
| The Swapper | 美學差異化、存在主義氛圍 |
| Leap Year | 美術風格 |
| Öoo | **克制機制數量**（最重要） |
| Cursor*10 | 教學速度極快 |

### 關鍵差異化

1. **錄製儀式有重量**：本體留原地的視覺儀式不在任何同類作品中出現
2. **光點 + Hotbar**：把錄製存檔變成空間化資產，而非選單上的條目
3. **殘骸是實體 + 時間視窗**：5 個有實體、舊的變痕跡的設計兼顧累積感與不混亂
4. **無自爆概念**：簡化心智模型

## 附錄：同類作品分析

### Cursor*10（2008，網頁）
- 機制：10 次嘗試、每次 20 秒固定、動作完整重播
- 啟示：第一個謎題要在 1 分鐘內讓玩家理解核心機制

### Braid（2008）— 世界 5「時間與決定」
- 機制：玩家有一個影子重複上次動作（單一世界小機制）
- 啟示：手感、手感、手感——分身會放大失誤

### The Misadventures of P.B. Winterbottom（2010）
- 機制：把錄製當主玩法的第一款商業作品；分身可堆疊、撞擊
- 啟示：分身要是物理實體；機制深度要靠新元素而非新機制

### The Swapper（2013）
- 機制：即時生成分身（非錄製）
- 啟示：美學定義差異化

### Leap Year（2024）
- 機制：跳得起來但摔下會死；不獲得新能力，只獲得對世界的理解
- 啟示：「同一地圖、重新閱讀」的設計

### Öoo（2025）
- 機制：爆炸毛毛蟲，全程只有兩顆炸彈不會增加
- 啟示：克制機制數量。**3-4 個核心機制比 7 個更深刻**

### Tick Tock Bang Bang（小眾獨立）
- 機制：錄製 ghost、可疊加多個（與本作重合度最高）
- 啟示：直接驗證「多 ghost 疊加」可行

### PICO PARK（2016+）
- 機制：2-8 人合作平台
- 啟示：合作謎題類型的素材庫——但要轉成「可預先規劃的編舞」
