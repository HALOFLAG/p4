## 一、可重用元件（components/）— 拖進場景就能用

> 位置：`godot/scenes/components/` — Inspector 內可調尺寸/顏色、@tool 即時預覽

| # | 元件 | 用途 | 主要 export | 引入 milestone |
|---|---|---|---|---|
| 1 | **PressButton** | 站上即觸發、鬆開復位 | width / color | M0-M10 |
| 2 | **Door** | 沉降式升降門 | door_height / width / door_color | M0-M10 |
| 3 | **Exit** | 通關偵測區（觸發結局） | size / color | M0-M10 |
| 4 | **Platform** | 矩形可重用平台 | size / color | M12 |
| 5 | **HazardZone** | 矩形致死區（DeathBand 等） | size / visual_color | M12 |
| 6 | **Lever** | 跨壓 toggle、0.5s 冷卻、latch | initial_state / color_on / color_off / size | M13 |
| 7 | **Spring** | 強制彈起、移動工具（非謎題核心） | bounce_velocity / size / color | M13 |
| 8 | **TriggeredPlatform** | 被 signal 驅動的移動平台、含沉降變體 | movement / move_duration / size / color | M13 |
| 9 | **CrumblingPlatform** | 踩 0.5s 後消失、checkpoint reset | size / color | M13b |

### 共通設計約定
- 全部為 `@tool` 腳本：Inspector 改參數、編輯器即時預覽視覺
- size 改變時 Polygon2D + CollisionShape2D 同步更新
- collision_layer / mask 統一：偵測類 layer=0 mask=3、實體類用預設

## 十一、三維矩陣標註

> 對應 [里程碑規劃 M13](../docs/實作進度與里程碑規劃.md) 的「三維矩陣」設計：每個機關用 3 個維度定位、確保關卡設計時不會偏向某一類。

| 維度 | 選項 |
|---|---|
| **玩家控制** | 直接（玩家主動操作觸發）/ 間接（觸發另一機關連帶觸發此機關）/ 無（環境自動觸發）|
| **時間性** | 即時（觸發瞬間生效）/ 延遲（觸發後 N 秒生效）/ 週期（規律重複）|
| **懲罰** | 死亡（觸發失敗即死）/ 回退（失敗要重做）/ 壓力（失敗有不便、但可救回）|

### 機關矩陣

| 機關 | 玩家控制 | 時間性 | 懲罰 | 類型 |
|---|---|---|---|---|
| **LogicGate（AND/OR/NOT）** | 間接 | 即時 | 無 | 邏輯抽象 |
| **PressCounter** | 直接（按下）| 即時 | 無 | 邏輯抽象 |
| **PressButton（壓力板）** | 直接 | 即時 | 無 | 互動觸發 |
| **Lever（拉桿）** | 直接 | 即時 | 無 | 高組合 |
| **Door（門）** | 間接 | 延遲（0.6s 開合）| 壓力（穿模時短暫卡）| 通行控制 |
| **Spring（彈簧）** | 無 | 即時 | 壓力（彈失方向錯）| 移動工具 |
| **TriggeredPlatform** | 間接 | 延遲（線性走完）| 壓力 | 高組合 |
| **CrumblingPlatform** | 無 | 延遲（0.5s）| 回退（需 reset）| 情境 |
| **HazardSpike / HazardZone** | 無 | 即時 | 死亡 | 危險物 |
| **Checkpoint** | 直接 | 即時 | 無 | 系統 |
| **Teleporter** | 直接 | 即時 | 無 | 系統 |

### 類型分布
- **高組合性（high-combo）**：Lever、TriggeredPlatform — 與多機關搭配出多種謎題
- **情境型（situational）**：CrumblingPlatform — 為特定設計情境（殘骸主題）量身
- **移動工具**：Spring — 擴展玩家移動、非謎題核心
- **邏輯抽象**：LogicGate、PressCounter — 連線用、組合既有元件
- **危險物**：Hazard 系列
- **系統**：Checkpoint / Teleporter — 全局服務

## 十二、未在清單中、明確不導入的機關

依 [玩法鎖定清單](../docs/玩法鎖定清單.md)、以下機關不會新增（除非進 v2.0）：

- ❌ 計時門（用 LogicGate + Tween 可組）
- ❌ NOT 按鈕（已被 LogicGate NOT mode 涵蓋）
- ❌ 移動平台變體（直線往返 / 圓周）— 用 TriggeredPlatform 替代
- ❌ 梯子（會改 Player 移動模式）
- ❌ 推箱子 / RigidBody2D（與 deterministic 衝突）
- ❌ 蹬牆跳 / 黏壁（改核心移動手感）
- ❌ 重力翻轉（與錄製系統衝突）
- ❌ 鋸刃 / 雷射 / 擺錘 / 砲彈（基調衝突）
- ❌ 鑰匙鎖（基調衝突）
- ❌ 順序鎖 / XOR-gate（複雜度過高）
